Sobre
Angular Material

Para projetos Sisbr 3.0 utilizando o Angular 11 o Sicoob disponibilizou uma biblioteca de componente visuais @sicoob/ui. Novos projetos desenvolvidos em Angular 15 utilizarão principalmente para formulários e listas, componentes do Angular Material Components, ficando a cargo do @sicoob/ui apenas componentes estruturais como modal, sidebar, header, navbar entre outros.

Design System

No link do Sicoob Design System disponibilizamos informações importantes de layout, grid, palheta de cores e fontes. Mas no capítulo de componentes desconsidere os relacionados a formulários.

NgRx/Redux

Esse projeto está configurado com o NgRx. Fica a critério de cada equipe utilizar ou não. Apenas recomendamos o uso com sabedoria, pois alguns dos problemas que o NgRx se propõe a resolver pode ser resolvido nativamente pelo Angular.
